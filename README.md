# Leave Management System

A full-stack leave management application that allows users to manage leave requests and track leave status through a role-based system.

## 🚀 Technologies

* Java
* Spring Boot
* React.js
* PostgreSQL
* REST APIs

## ✨ Features

* User and role-based access
* Leave request management
* Leave status tracking
* RESTful backend APIs
* PostgreSQL database integration
* Full-stack web interface

## 🏗️ Project Overview

The application provides a centralized platform for managing employee leave requests. The Spring Boot backend exposes RESTful APIs, while React.js provides the frontend interface and PostgreSQL handles persistent data storage.

## 🔐 Role-Based Access

Different users can access functionality according to their assigned roles.
